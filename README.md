## Usage:

You **cannot** deploy Black-waves on static hosting services. This includes Netifly, GitHub Pages, Vercel, etc.

## Self-Hosting:

Black-waves is simple to self-host.

1. Open your terminal.
2. Run the commands bellow:
   
```bash
git clone https://github.com/yaanscoat/black-waves

cd black-waves

sh setup.sh
```
